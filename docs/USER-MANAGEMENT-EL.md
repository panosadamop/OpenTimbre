# Διαχείριση χρηστών & ρόλων

Ανοίξτε τη **Διαχείριση** στο Studio. Η καρτέλα εμφανίζεται μόνο σε λογαριασμούς με το δικαίωμα *Προβολή χρηστών* ή *Προβολή ιστορικού*.

## Ρόλοι και δικαιώματα

Κάθε χρήστης έχει ακριβώς έναν ρόλο. Ένας ρόλος είναι ένα σύνολο δικαιωμάτων:

| Δικαίωμα | Id | Επιτρέπει |
|---|---|---|
| Cloud workspace | `workspace.use` | Αποθήκευση συνθέσεων, ανέβασμα ηχογραφήσεων, βιβλιοθήκες οργάνων |
| Δημοσίευση στον κατάλογο | `catalogue.publish` | Δημοσίευση metadata βιβλιοθηκών |
| Σύνθεση ήχου | `synthesis.use` | Εργασίες σύνθεσης DSP και neural |
| Εκπαίδευση μοντέλων | `neural.train` | Εκπαίδευση μοντέλων σε συνδεδεμένες ηχογραφήσεις |
| Ανάλυση ηχογραφήσεων | `recordings.analyze` | AI βοηθός ηχογράφησης |
| Προβολή χρηστών | `users.view` | Λίστα χρηστών, ρόλοι, στατιστικά |
| Διαχείριση χρηστών | `users.manage` | Δημιουργία, επεξεργασία, απενεργοποίηση, κωδικοί, αποσύνδεση, διαγραφή |
| Διαχείριση ρόλων | `roles.manage` | Δημιουργία/επεξεργασία/διαγραφή ρόλων και ανάθεση ρόλων |
| Προβολή ιστορικού | `audit.view` | Ιστορικό συνδέσεων και ενεργειών διαχείρισης |

Ενσωματωμένοι ρόλοι:

- **Superadmin**: όλα τα δικαιώματα. Είναι κλειδωμένος: δεν επεξεργάζεται και δεν διαγράφεται.
- **Administrator**: όλες οι λειτουργίες στούντιο, συν προβολή και διαχείριση χρηστών και ιστορικό. Δεν αλλάζει ρόλους.
- **User**: όλες οι λειτουργίες στούντιο. Είναι ο προεπιλεγμένος ρόλος για νέες εγγραφές, και οι υπάρχοντες χρήστες διατηρούν την ίδια πρόσβαση που είχαν.

Στην καρτέλα **Ρόλοι & δικαιώματα** δημιουργείτε προσαρμοσμένους ρόλους. Ένας προσαρμοσμένος ρόλος διαγράφεται μόνο όταν δεν τον έχει κανένας χρήστης.

## Χρήστες

- **Νέος χρήστης**: ο κωδικός δημιουργείται αυτόματα (εμφανίζεται μία φορά) ή ορίζεται χειροκίνητα (12+ χαρακτήρες).
- **Επεξεργασία**: όνομα, email (μόνο σε λογαριασμούς με κωδικό), ρόλος, ενεργός/ανενεργός.
- **Επαναφορά κωδικού**: τερματίζει όλες τις συνεδρίες του χρήστη.
- **Αποσύνδεση παντού**: τερματίζει κάθε ενεργή συνεδρία του χρήστη.
- **Απενεργοποίηση**: ο χρήστης δεν μπορεί να συνδεθεί και αποσυνδέεται αμέσως. Αναιρείται.
- **Διαγραφή**: οριστική, μαζί με όλα τα δεδομένα του workspace και τα μοντέλα του. Απαιτεί πληκτρολόγηση του email για επιβεβαίωση.

## Δικλείδες ασφαλείας

Ελέγχονται από το API, όχι μόνο από το UI:

- Μόνο superadmin τροποποιεί άλλον superadmin ή δίνει τον ρόλο Superadmin.
- Κανείς δεν μπορεί να δώσει δικαιώματα που δεν έχει ο ίδιος.
- Δεν μπορείτε να αλλάξετε τον δικό σας ρόλο, να απενεργοποιήσετε ή να διαγράψετε τον εαυτό σας.
- Πρέπει να υπάρχει πάντα τουλάχιστον ένας ενεργός superadmin.

Το CLI `create_superadmin.py` παραμένει διαθέσιμο για τον πρώτο superadmin και για ανάκτηση πρόσβασης.

## Αναβάθμιση

Η βάση μεταφέρεται αυτόματα στην πρώτη εκκίνηση. Κρατήστε αντίγραφο ασφαλείας του `auth.sqlite3` πριν την αναβάθμιση σε παραγωγή. Λεπτομέρειες API: [USER-MANAGEMENT-EN.md](USER-MANAGEMENT-EN.md).
