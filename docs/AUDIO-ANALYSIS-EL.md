# Έλεγχος ηχογραφήσεων — v1.0

Το authenticated endpoint `POST /api/v1/recordings/analyze` δέχεται `multipart/form-data` με πεδίο `file` (PCM WAV, 16/32-bit, mono/stereo, έως 40 MB και 120 s). Επιστρέφει διάρκεια, sample rate, στάθμες peak/RMS, ποσοστό clipping, εκτιμώμενη συχνότητα, MIDI νότα, απόκλιση σε cents, confidence και προειδοποιήσεις.

Στο API documentation (`http://localhost:8000/docs`), συνδεθείτε πρώτα από το Studio και δοκιμάστε το endpoint. Η ανίχνευση είναι **ευρετική**, προορίζεται για μονοφωνικές νότες και μπορεί να σφάλλει σε ούτι/σάζι λόγω αρμονικών ή μικροδιαστημάτων. Δεν αναγνωρίζει τεχνικές παιξίματος ούτε διορθώνει αυτόματα τα αρχεία. Για έλεγχο αναφοράς από άλλη βιβλιοθήκη απαιτείται να έχετε δικαιώματα χρήσης.
