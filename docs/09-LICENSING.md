# Licensing and Provenance

## Proposed project licenses
- Source code: MIT (or another consciously selected OSI-approved license).
- Original sound recordings: CC0-1.0 if the recordist/performer can legally dedicate rights; alternatively CC BY 4.0 if attribution is required.
- Documentation: CC BY 4.0 optional; choose and document consistently.

## Rules
- Code license does not automatically license audio content.
- Each instrument pack MUST declare author, license, provenance, permission and third-party credits.
- Do not package samples from other libraries without verifying **redistribution** rights, derivative rights, attribution obligations and commercial use.
- Never assume a GitHub repo's license covers its sound files.
- Maintain `THIRD_PARTY_NOTICES.md` and machine-readable attribution metadata.
- Distinguish demo synthetic tones from real sampled instruments.

## Publication artifacts
`LICENSE` (code), `SAMPLES-LICENSE.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `THIRD_PARTY_NOTICES.md`, per-pack `LICENSE` and `CREDITS.md`.

## Contributions
Require contributors to certify they own or have permission to license submitted recordings and obtain performer/recordist permissions where needed. Review potential copyrighted musical performances embedded in recordings.
