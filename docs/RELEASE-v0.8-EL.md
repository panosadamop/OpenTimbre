# OpenTimbre v0.8 — Χρήστες, βιβλιοθήκες και demo

## Superadmin
Δεν παρέχεται προεπιλεγμένος κωδικός. Ορίστε `AUTH_SECRET` (τουλάχιστον 32 τυχαίοι χαρακτήρες) στο `.env`. Εκτελέστε στον backend container:

```bash
 docker compose -f docker-compose.neural.yml exec -e ADMIN_EMAIL=admin@example.org synthesis python create_superadmin.py
```

Θα ζητηθεί ασφαλής κωδικός (τουλάχιστον 12 χαρακτήρες). Αν ο χρήστης υπάρχει, προάγεται σε superadmin. Η οθόνη **Διαχείριση** εμφανίζει τους χρήστες, αλλά μόνο ο superadmin έχει πρόσβαση. Δεν υποστηρίζεται αλλαγή ρόλων από UI.

## Προσωπικές βιβλιοθήκες
Στο Cloud Workspace αποθηκεύετε συνθέσεις, WAV ηχογραφήσεις και metadata βιβλιοθηκών. Επιλέγετε `Private` ή `Public metadata` και άδεια. Η δημόσια λίστα εμφανίζει μόνο βιβλιοθήκες με επιτρεπτή άδεια CC0 ή CC BY. Τα αρχεία WAV παραμένουν ιδιωτικά και **δεν** διαμοιράζονται. Οι νευρωνικές εργασίες παραμένουν σε κοινό storage: **όχι παραγωγή πολλών χρηστών**.

## Demo όργανα
Στο Player επιλέξτε ένα από τα 9 demo όργανα. Δημιουργήστε τα αρχεία με `npm run fixtures`. Όλοι οι ήχοι είναι συνθετικοί (DSP), όχι πραγματικές ηχογραφήσεις ούτε neural models. Απαιτείται επαναδημιουργία Docker image για ενημέρωση των fixtures.
