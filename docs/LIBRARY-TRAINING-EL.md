# OpenTimbre v0.9 — Προσωπικές βιβλιοθήκες και AI Training

1. Συνδεθείτε στον λογαριασμό σας.
2. Στο Cloud Workspace δημιουργήστε βιβλιοθήκη τύπου **Oud** ή **Saz**.
3. Ανεβάστε τουλάχιστον δύο WAV (PCM 16/32-bit, έως 15 δευτερόλεπτα για εκπαίδευση). Δηλώστε σωστά τη νότα MIDI. Για ποιοτικό αποτέλεσμα χρησιμοποιήστε περισσότερες νότες και δυναμικές.
4. Στην περιοχή «Σύνδεση ηχογραφήσεων με βιβλιοθήκη», επιλέξτε βιβλιοθήκη και ηχογράφηση και πατήστε «Σύνδεση». Η επιλογή είναι προσωπική και ελέγχεται στο backend.
5. Στο Neural Instruments επιλέξτε το όργανο και την προσωπική βιβλιοθήκη. Πατήστε «Εκπαίδευση μοντέλου».
6. Στο Instrument Generator επιλέξτε Local Neural και εισαγάγετε το Model ID.

**Πεδία:** Library: βιβλιοθήκη εκπαίδευσης. WAV: ηχογράφηση. MIDI: πραγματική νότα. Velocity: ένταση (η σύνδεση χρησιμοποιεί προεπιλογή 90). Model ID: μοναδικό αναγνωριστικό προσωπικού μοντέλου.

**Περιορισμοί:** μόνο ούτι/σάζι, δύο ή περισσότερες ηχογραφήσεις, harmonic MLP baseline, όχι εγγυημένος φυσικός ήχος. Δεν έχει υλοποιηθεί αυτόματος συγχρονισμός του browser sampler. Η εκπαίδευση είναι σύγχρονη και μπορεί να διαρκέσει.
