# OpenTimbre — Πλήρες εγχειρίδιο χρήσης (Ελληνικά)

**Έκδοση:** 0.2.0 · **Χρήση:** τοπικό web studio · **Κατάσταση:** αναπτυσσόμενη έκδοση, όχι πιστοποιημένη παραγωγική εγκατάσταση.

## 1. Σκοπός και όρια

Το OpenTimbre εισάγει πραγματικά ηχογραφημένες νότες WAV, αντιστοιχίζει MIDI περιοχές, παίζει απλές μελωδίες, αποθηκεύει τοπικά την εργασία και εξάγει WAV/JSON/SFZ/MIDI. Το demo περιλαμβάνει **συνθετικούς** ήχους, όχι πραγματικό ούτι/σάζι. Δεν διαθέτει πολυκάναλη ηχογράφηση DAW, αυτόματο trimming/normalization, cloud collaboration, πλήρη SFZ συμβατότητα, ούτε ολοκληρωμένο MIDI 2.0/MPE. Το MIDI import/export δεν διατηρεί μικροτονικά pitch bends.

## 2. Εξοπλισμός ηχογράφησης

**Ελάχιστος:** ούτι ή σάζι σε καλή κατάσταση, ήσυχος χώρος, υπολογιστής, USB audio interface 24-bit, πυκνωτικό μικρόφωνο, βάση, καλώδιο XLR, ακουστικά κλειστού τύπου, πρόγραμμα ηχογράφησης (π.χ. Audacity ή Reaper). Αν το μικρόφωνο χρειάζεται phantom power, ενεργοποιήστε 48 V σύμφωνα με τις οδηγίες του κατασκευαστή. Προαιρετικά: pop/wind protection, δεύτερο μικρόφωνο, ακουστικά πάνελ, χρωματικό κουρδιστήρι, μετρονόμος.

**Στόχος:** mono WAV PCM 24-bit, 48 kHz, χωρίς reverb, compression, limiter ή EQ κατά την εγγραφή. Κρατήστε τα ακατέργαστα master αρχεία. Το browser μπορεί να αποκωδικοποιήσει συνήθεις WAV μορφές, αλλά ελέγξτε το αποτέλεσμα.

## 3. Πρακτική ηχογράφηση ούτι και σαζιού

1. Επιλέξτε και καταγράψτε κούρδισμα, χορδή, θέση, πένα, θερμοκρασία και ημερομηνία. Κουρδίστε ξανά συχνά.
2. Τοποθετήστε το μικρόφωνο περίπου 20–40 cm από το ηχείο, προς την περιοχή ανάμεσα στη γέφυρα και την ταστιέρα. Αποφύγετε να σημαδεύει απευθείας την οπή. Δοκιμάστε και ακούστε πριν σταθεροποιήσετε τη θέση.
3. Ρυθμίστε gain ώστε οι δυνατές νότες να κορυφώνονται περίπου -12 έως -6 dBFS χωρίς clipping. Κλείστε ανεμιστήρες, ειδοποιήσεις και κλιματισμό όπου είναι εφικτό.
4. Για κάθε νότα ηχογραφήστε **3 δυναμικές** (soft, medium, hard) και **3 διαφορετικές λήψεις** (round robin). Αφήστε πλήρη φυσική απόσβεση και 0,2–0,5 s καθαρού περιθωρίου στην αρχή.
5. Κάντε ξεχωριστά upstroke/downstroke, tremolo, muted και slides. Για το σάζι καταγράψτε την ίδια νότα σε διαφορετικές χορδές όπου έχει διαφορετικό ηχόχρωμα.
6. Ακούστε με ακουστικά για clicks, τρίξιμο, clipping, αναπνοές και θορύβους. Κόψτε προσεκτικά την αρχή/τέλος και χρησιμοποιήστε μικρά fades χωρίς να αφαιρείτε το attack ή το release.
7. Εξάγετε κάθε λήψη ως ξεχωριστό WAV και ονομάστε τη συστηματικά: `oud_D4_soft_rr01_down.wav` ή `saz_G3_hard_rr02_up.wav`.
8. Σημειώστε τη νότα σε MIDI (π.χ. C4=60), τυχόν απόκλιση cents, τη δυναμική, την τεχνική, την πραγματική χορδή και την άδεια. Η θέση χορδής μπορεί προς το παρόν να καταγραφεί σε εξωτερικό CSV.

**Πρώτη συνεδρία:** 12–24 νότες × 3 δυναμικές × 3 λήψεις = 108–216 WAV ανά όργανο. Ξεκινήστε με μικρότερο υποσύνολο για έλεγχο ποιότητας.

## 4. Εγκατάσταση και εκτέλεση

Απαιτείται Node.js 22+ και npm. Στον φάκελο του project εκτελέστε `npm install`, `npm run fixtures`, `npm run dev` και ανοίξτε `http://localhost:5173`. Για build: `npm run build`. Για tests: `npm test`. Εναλλακτικά: `docker compose up --build`, έπειτα `http://localhost:8080`.

## 5. Βασική ροή εργασίας

1. Στην **Play** πατήστε Load demo instrument για να επιβεβαιώσετε ότι λειτουργεί ο ήχος.
2. Στη **Library** ορίστε όνομα οργάνου και άδεια, επιλέξτε πρώτη root note και εισάγετε τα δικά σας WAV.
3. Διορθώστε τις τιμές Root, Low, High, velocity layers και Root cents. Αποφύγετε επικαλυπτόμενες περιοχές αν δεν επιδιώκετε εναλλακτικές λήψεις.
4. Στην **Play** δοκιμάστε το εικονικό πληκτρολόγιο και επιλέξτε tuning preset.
5. Στη **Song** προσθέστε/τροποποιήστε note events, πατήστε Play song και ελέγξτε την ενορχήστρωση.
6. Πατήστε **Save workspace**. Στην **Export** εξάγετε WAV, song JSON, instrument JSON και SFZ. Διατηρήστε αντίγραφα των πρωτότυπων WAV.

## 7. Προβλήματα και λύσεις

- **Δεν ακούγεται ήχος:** πατήστε πρώτα ένα πλήκτρο (ο browser απαιτεί αλληλεπίδραση), ελέγξτε έξοδο ήχου και αν υπάρχει sample στη σωστή MIDI περιοχή/δυναμική.
- **Missing sample:** εισάγετε ξανά τα WAV μετά από import μόνο του manifest. Το manifest δεν περιέχει ήχο.
- **Παίζει λάθος νότα:** ελέγξτε Root, Root cents, Low/High και κούρδισμα.
- **Το MIDI δεν διατηρεί cents:** χρησιμοποιήστε Song JSON για μικροτονικά δεδομένα και WAV για τελικό ήχο.
- **Αποτυχία αποθήκευσης:** ο browser μπορεί να έχει εξαντλήσει quota ή να είναι σε private mode. Εξάγετε JSON και κρατήστε τα WAV εκτός browser.
- **SFZ δεν βρίσκει WAV:** διατηρήστε τη σχετική διαδρομή `samples/...` και τοποθετήστε τα αρχεία δίπλα στο SFZ με τη σωστή δομή.

## 8. Δικαιώματα, ασφάλεια, αντίγραφα

Χρησιμοποιείτε μόνο ηχογραφήσεις με άδεια χρήσης. Η άδεια του λογισμικού δεν καλύπτει αυτομάτως τα samples. Η αποθήκευση IndexedDB παραμένει στο συγκεκριμένο browser/profile και μπορεί να χαθεί αν καθαρίσετε δεδομένα. Κρατήστε αντίγραφα WAV, JSON και τελικών εξαγωγών. Μην εισάγετε αρχεία από μη έμπιστες πηγές.

## 9. Προτεινόμενη επέκταση

Αυτόματη ανίχνευση νότας, waveform editor, batch mapping με ονοματοδοσία, πλήρες round-robin, articulation keyswitches, loop points, πολλαπλά tracks, MPE/MTS, Scala import και πακετάρισμα samples σε ZIP. Αυτά **δεν** περιλαμβάνονται ως ολοκληρωμένες λειτουργίες στην τρέχουσα έκδοση.


## External libraries and synthetic instruments / Εξωτερικές βιβλιοθήκες και συνθετικά όργανα

### Πηγές & Σύνθεση
Η οθόνη **Πηγές & Σύνθεση** επιτρέπει καταχώριση βιβλιοθηκών ως αναφορά, υποψήφια εισαγωγή ή διόρθωση.
- **Όνομα πηγής**: ελεύθερη περιγραφή. **HTTPS URL / GitHub repo**: σύνδεσμος βιβλιοθήκης.
- **Χρήση**: Reference (αναφορά), Correction (διόρθωση), Import candidate (υποψήφια εισαγωγή).
- **Άδεια**: καταχώρισε την πραγματική άδεια ή Unknown. **Σημειώσεις**: παρατηρήσεις ποιότητας ή διορθώσεων.
- **Αποθήκευση πηγής**: τοπική καταχώριση στον browser. **Έλεγχος instrument.json**: ανάκτηση συμβατού JSON από HTTPS, εφόσον επιτρέπεται CORS.
- **Άνοιγμα τοπικού manifest**: εισαγωγή JSON χωρίς WAV. **Σύγκριση manifest**: εμφανίζει διαφορές MIDI root notes και αριθμό samples.
- **Χρήση manifest**: αντικαθιστά μόνο metadata, όχι ήχους.
- **Όργανο / Πρώτη / Τελευταία νότα MIDI**: παράμετροι δημιουργίας συνθετικού ούτι ή σαζιού.
- **Δημιουργία και φόρτωση**: δημιουργεί WAV και τα φορτώνει στο Player. Πρόκειται για φυσικά εμπνευσμένη σύνθεση, ΟΧΙ εκπαιδευμένο μοντέλο AI.
**Περιορισμοί**: Δεν γίνεται αυτόματη λήψη ολόκληρων GitHub repositories ή ZIP, ούτε ανακατασκευή αυθεντικού ηχοχρώματος από ένα κείμενο. Οι άδειες τρίτων απαιτούν ανεξάρτητο έλεγχο.


## Δημιουργία ήχων AI / DSP (v0.4)
Άνοιξε **Sources & Synthesis → Instrument generation**. Εκκίνησε το Python backend (`docker compose up --build` ή `cd services/ai && pip install -r requirements.txt && uvicorn server:app --reload`). Επίλεξε Engine (DSP = όχι AI, Neural = απαιτεί δικό σου εκπαιδευμένο μοντέλο), Instrument (ούτι/σάζι), MIDI note (24–96), Velocity (1–127), Duration (0,15–8 δευτερόλεπτα), Articulation (sustain/tremolo/muted), Seed (επαναληψιμότητα) και Rights/provenance (περιγραφή δικαιωμάτων). Πάτησε Generate WAV, παρακολούθησε το job, άκουσε τον ήχο, κατέβασε WAV ή επίλεξε Import to Library. Στη συνέχεια αποθήκευσε το Workspace. Η επιλογή Neural είναι ανενεργή χωρίς συνδεδεμένο μοντέλο. Ο παραγόμενος ήχος δεν αποτελεί πιστή προσομοίωση πραγματικού οργάνου.


## Neural Instruments / Εκπαίδευση (v0.5)
Στην οθόνη **Πηγές & Σύνθεση → Neural Instruments** επιλέξτε όργανο, WAV, πραγματική MIDI νότα και δυναμική (1–127). Το πεδίο «Δήλωση δικαιωμάτων» απαιτεί επιβεβαίωση ότι έχετε άδεια χρήσης. Πατήστε «Προσθήκη ηχογράφησης» για κάθε δείγμα και στη συνέχεια «Εκπαίδευση μοντέλου». Χρειάζονται τουλάχιστον δύο WAV (16/32-bit PCM, 8–96 kHz, έως 15 s και 5 MB ανά αρχείο). Το backend εκπαιδεύει μικρό νευρωνικό δίκτυο που προβλέπει 24 αρμονικές. Δεν είναι πλήρης neural audio codec ούτε εγγυάται ρεαλιστικό ηχόχρωμα. Στο Instrument Generator επιλέξτε **Local Neural** και το model ID. Για καλύτερα αποτελέσματα χρησιμοποιήστε πολλά καθαρά δείγματα από διαφορετικές νότες και δυναμικές. Τα uploads αποθηκεύονται προσωρινά στη μνήμη, ενώ τα μοντέλα στον Docker volume. Εκτός Docker: `pip install -r services/ai/requirements-neural.txt`. Εκκίνηση: `docker compose -f docker-compose.neural.yml up --build`.
